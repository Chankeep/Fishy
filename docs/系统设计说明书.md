# **现代 Vulkan 渲染引擎 MVP 1.0 \- 系统设计说明书**

## **1\. 系统架构概览**

系统采用分层架构，核心原则是**数据与逻辑分离**以及**显式同步**。

``` graph TD  
    A\[Platform Layer (Window, Input)\] \--\> B\[Core Layer (Device, Swapchain, RHI)\]  
    B \--\> C\[Resource Layer (Texture, Buffer, Shader)\]  
    C \--\> D\[Render Layer (Passes, Pipeline, Frames)\]  
    E\[Scene Layer (SceneGraph, Components)\] \--\> D  
    F\[App Layer (Editor, GameLoop)\] \--\> E
```

## **2\. 关键类与模块设计**

### **2.1 核心上下文 (VulkanContext)**

负责全局对象的生命周期管理。单例或通过指针传递。

*   **Initialization (vk-bootstrap):** 使用 `vk-bootstrap` 简化 Instance/Device 创建与 Physical Device 选择流程 (支持 Validation Layers 自动配置)。
*   **Function Loading (volk):** 使用 `volk` 动态加载 Vulkan 函数指针，配合 `VK_NO_PROTOTYPES` 避免静态链接开销，同时支持直接驱动调用 (Direct Dispatch) 提升性能。
*   **Wrappers (vulkan-hpp):** 结合 `vulkan-hpp RAII` + Dynamic Dispatcher，实现类型安全且高效的 API 调用。

*   vk::raii::Instance, vk::SurfaceKHR
*   vk::raii::PhysicalDevice, vk::Device
*   vk::Queue (Graphics, Present, Transfer)
*   VmaAllocator (内存分配器)

### **2.2 帧资源管理 (FrameData)**

**设计核心：** 解决多帧并行问题。

struct FrameData {  
    // 同步原语  
    VkSemaphore \_presentSemaphore, \_renderSemaphore;  
    VkFence \_renderFence;

    // 命令管理  
    VkCommandPool \_commandPool;  
    VkCommandBuffer \_mainCommandBuffer;

    // 动态数据缓冲 (解决 CPU 写 GPU 读的冲突)  
    AllocatedBuffer \_cameraBuffer; // 存储 View/Projection  
    AllocatedBuffer \_objectBuffer; // 存储当前帧所有物体的 Model Matrix  
    VkDescriptorSet \_globalDescriptor;  
};

### **2.3 渲染器 (Renderer)**

渲染循环的主控类。

* **成员:**  
  * FrameData \_frames\[FRAME\_OVERLAP\] (通常为 2\)  
  * uint32\_t \_frameNumber  
* **核心方法 Draw():**  
  1. vkWaitForFences(): 等待 CPU 这一帧的资源可用。  
  2. vkResetFences(): 重置栅栏。  
  3. vkAcquireNextImageKHR(): 获取 Swapchain 图像索引。  
  4. frameData.commandBuffer.reset(): 重置命令缓冲。  
  5. frameData.commandBuffer.begin(): 开始录制。  
  6. **Execute Passes**:  
     * Binding Global UBO (Camera data).  
     * Binding Pipeline.  
     * Loop through RenderObjects \-\> Bind PushConstants/Textures \-\> DrawIndexed.  
   7. **UI Pass (IMGUI):**  
      * `ImGui_ImplVulkan_NewFrame()` / `ImGui_ImplGlfw_NewFrame()`
      * 构建 UI (Resource Browser, Material Editor).
      * `ImGui::Render()` -> `ImGui_ImplVulkan_RenderDrawData()`.
   8. vkQueueSubmit(): 提交命令，附带 Signal Semaphore (包括 UI 渲染)。  
   9. vkQueuePresentKHR(): 呈现图像，等待 Semaphore。  
   10. \_frameNumber++: 切换到下一帧索引。

### **2.4 资源系统 (ResourceManager)**

基于哈希的缓存池。

* std::unordered_map<size_t, Texture> _textureCache;  
* std::unordered_map<size_t, Mesh> _meshCache;  
* std::unordered_map<size_t, Material> _materialCache;

**动态资源管理 (Runtime):**
* `Model Loading`: 支持 `.obj` / `.gltf` (使用 `tinyobjloader` / `fastgltf`)。
* `Hot Reload`: 材质改变时通过 `vkUpdateDescriptorSets` 实时更新 Set，或者重建 Descriptor Set。
* **Descriptor Allocator:** 使用 Growable Pool 策略。  
  * allocate(layout): 从当前 Pool 分配，如果满了就创建一个新 Pool。  
  * reset_pools(): 在帧开始时重置所有 Pool (针对每一帧临时的 Descriptor)。
  * **IMGUI Pool**: 独立的 Descriptor Pool 用于 UI 纹理注册。

### **2.5 场景与变换 (TransformSystem)**

数据导向设计 (DoD) 的体现。

struct RenderObject {  
    uint32\_t meshID;  
    uint32\_t materialID;  
    uint32\_t transformID; // 指向 TransformSystem 的索引  
    AABB boundingBox;  
};

class TransformSystem {  
    std::vector\<glm::mat4\> localMatrices;  
    std::vector\<glm::mat4\> worldMatrices;  
    std::vector\<bool\> dirtyFlags;  
      
    void UpdateHierarchies(); // 批量计算父子变换  
};

## **3\. 渲染管线配置 (Render Pipeline Config)**

### **3.1 描述符布局 (Descriptor Layouts)**

* **Set 0 (Global):** \* Binding 0: Scene UBO (Camera, Light, Time) \- Vertex/Fragment  
* **Set 1 (Object):**  
  * Binding 0: Object SSBO/UBO (Model Matrices) \- Vertex  
* **Set 2 (Material):**  
  * Binding 0: Albedo Texture  
  * Binding 1: Normal Texture  
  * Binding 2: Material Parameters (UBO)

### **3.2 顶点输入 (Vertex Input)**

标准 PBR 顶点格式：

struct Vertex {  
    glm::vec3 position;  
    glm::vec3 normal;  
    glm::vec3 color;  
    glm::vec2 uv;  
};

## **4\. 数据流 (The Game Loop)**

1. **Poll Events:** 处理输入。  
2. **Scene Update:** \* 移动相机。  
   * 更新物体 Local Transform。  
   * TransformSystem::Update(): 计算所有 dirty 的世界矩阵。  
3. **Culling (CPU):** \* 遍历 RenderObject 数组。  
   * 将 RenderObject.AABB \* WorldMatrix 与 CameraFrustum 进行相交测试。  
   * 生成 std::vector\<uint32\_t\> visibleIndices。  
4. **Upload Data:**  
   * 将相机数据写入当前帧的 \_cameraBuffer。  
   * 将可见物体的矩阵数据写入当前帧的 \_objectBuffer。  
5. **Render (GPU):**  
   * 调用 Renderer::Draw(visibleIndices)。

## **5. 交互系统 (Interactive System)**

为了支持运行时动态编辑，集成 **Dear ImGui (Docking Branch)**。

### **5.1 核心功能模块**

1.  **场景大纲 (Scene HierarchyPanel):**
    *   列出当前场景中所有的 `RenderObject`。
    *   点击选中物体，并在 Inspector 中显示详情。

2.  **属性面板 (Inspector Panel):**
    *   **Transform:** 实时编辑 Position / Rotation / Scale。
    *   **Material:** 显示当前材质名称，提供下拉框切换材质。

3.  **资源浏览器 (Asset Browser):**
    *   浏览文件系统。
    *   **Import:** 加载模型 (`.obj`, `.gltf`) -> 生成 `Mesh` 并添加到 `MeshCache`。
    *   **Import:** 加载贴图 (`.png`, `.jpg`) -> 生成 `Texture` 并添加到 `TextureCache`。

4.  **材质编辑器 (Material Creator):**
    *   创建新材质 (New Material)。
    *   为 PBR 属性 (Albedo, Normal, Metallic, Roughness) 分配贴图资源。
    *   调整材质参数 (如无贴图时的纯色/粗糙度数值)。

### **5.2 输入处理**

*   **Input Capture:** 当 ImGui `WantCaptureMouse` 或 `WantCaptureKeyboard` 为真时，屏蔽场景相机的输入控制，避免操作 UI 时误触场景漫游。
